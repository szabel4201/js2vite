### CO MAMY?

Rok 2026. I działającą grę tekstową w JavaScript. Uruchamianą z poziomu przeglądarki, a konkretniej - konsoli developera. 

Gra wykorzystuje:

- stałe
- zmienne
- funkcje
- instrukcje warunkowe
- pętle

### CO DO ZMIANY?

| Problem                                            | Rozwiązanie                         | Po co                                                     |
| -------------------------------------------------- | ----------------------------------- | --------------------------------------------------------- |
| Stan jest rozrzucony po zmiennych                  | Obiekt                              | Całą sytuację gracza można przekazać jako jedną wartość   |
| Pozorna kopia zmienia oryginał                     | Referencje i spread                 | Można porównać sytuację przed i po działaniu              |
| Nazwy pokojów są ukryte w switch                   | Tablica rekordów                    | Dane mapy można przeglądać i przetwarzać jednym przepisem |
| Funkcja jednocześnie zmienia dane i wypisuje tekst | Funkcja przejścia i obiekt wyniku   | Regułę można wywołać bez konsoli i bez zmiany wejścia     |
| Wszystko mieszka w jednym pliku                    | Zwykłe skrypty i uzgodnione funkcje | Wiadomo, gdzie są reguły, a gdzie sterowanie aplikacją    |
| Odświeżenie kasuje postęp                          | JSON oraz ręczny zapis tekstu       | Stan można zapisać i odtworzyć                            |
| Wczytany tekst może zawierać bzdury                | Walidacja i try/catch               | Błędny zapis nie niszczy działającej rozgrywki            |
